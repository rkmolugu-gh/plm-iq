# New fields introduced in v2:
#   version (int, optional)
#       Format version. v2 or absent = v1 compatibility mode.
#
#   start (datetime, optional)
#       Workflow start date/time. Set when workflow is instantiated.
#
#   end (datetime, optional)
#       Workflow end date/time. Set when workflow completes or is cancelled.
#
#   metadata (object, optional)
#       Workflow-level metadata including name, description, owner, timestamps.
#
#   Per-step:
#     description (str, optional)
#         Human-readable description shown in visualization and instance panel.
#     due_days (int, optional)
#         Days from the stage's start date. Computed to an absolute due_date
#         when tasks are created (falls back to instance-level due_date).
#     allowed_actions (array[str], optional)
#         Actions allowed on this step. Default: ["accept", "reject"].
#     notification (str, optional)
#         Notification target. Format: "email:address@domain.com".
#
#   Per-parallel-stage:
#     threshold (int, optional, default = all)
#         Number of approvals required for the stage to complete.
#         When reached, remaining pending peer tasks are SUPERSEDED.
#
#   Normalized assignee syntax:
#     assignee: "role:<role_name>" | "user:<user_id>"
#         Combined format replacing assignee_type + assignee fields.
#
#   Parallel stage default:
#     If "parallel" is not specified, it defaults to false.
