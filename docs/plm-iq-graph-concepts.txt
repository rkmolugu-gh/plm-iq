PLM-IQ GRAPH CONCEPTS

CORE VOCABULARY
Node = PLM business object
Edge = directed connection between nodes
Edge Type = semantic meaning of an edge
Edge Property = structured data carried by an edge
Edge Annotation = human/AI commentary on an edge
Edge Evidence = source supporting an edge or conclusion
Edge Impact = assessed effect of a change
Graph Traversal = navigation through edges
Path = sequence of nodes and edges
Subgraph = selected graph region
Neighborhood = directly connected nodes
Upstream = contributing/source nodes
Downstream = dependent/affected nodes
Lineage = derivation/history path
Traceability = connected cross-domain path
Impact Set = candidate affected nodes
Change Propagation = traversal of impact through the graph

GRAPH TRAVERSAL
Direct neighbors = nodes one edge away
Upstream traversal = source/contributing dependencies
Downstream traversal = dependent/affected nodes
Dependency traversal = follow DEPENDS_ON
Structure traversal = follow HAS_COMPONENT/HAS_SUBASSEMBLY
Traceability traversal = Requirement -> Product -> CAD -> Drawing -> Test -> Change
Change propagation = changed node -> relevant edges -> impacted nodes -> further traversal

GRAPH GOVERNANCE
1. Store one canonical direction for each semantic edge.
2. Define inverse edge types instead of duplicate edges.
3. Keep authoritative domain data in domain tables.
4. Use the graph as the relationship/traceability layer.
5. Preserve history for controlled PLM edges.
6. Distinguish human assertions from AI inference.
7. Require evidence for AI impact conclusions.
8. Do not allow an LLM to directly mutate authoritative graph state.
9. Govern edge types centrally.
10. Apply tenant security to nodes and edges.

PLM-IQ PRINCIPLE
Nodes represent WHAT exists.
Edges represent HOW things are connected.
Edge properties represent structured relationship facts.
Edge annotations represent WHY the relationship matters.
Edge evidence represents WHY we believe it.
Impact assessments represent WHAT a change means.
AI agents reason over the graph but do not own authoritative truth.
